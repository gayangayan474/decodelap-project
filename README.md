# DecodeLabs Project 3: Database Integration

## 📌 Overview
This repository contains the completion of **Project 3: Database Integration** for the DecodeLabs Full Stack Development training. The goal of this project is to bridge application logic with permanent storage by designing a relational database schema and executing RESTful CRUD operations.

## 🛠️ Technologies Used
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Driver:** `pg` (Node Postgres)
